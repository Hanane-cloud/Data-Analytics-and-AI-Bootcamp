# Data Analytics & AI Bootcamp Portfolio

Welkom op mijn portfolio! Na het succesvol afronden van mijn intensieve Data Analytics bootcamp, heb ik deze repository ingericht om mijn vaardigheden te demonstreren. Ik ben gespecialiseerd in het omzetten van ruwe data naar interactieve en actiegerichte dashboards met behulp van de Microsoft BI-stack.

##  Technische Skills
* **Datapreparatie & ETL:** Power Query (opschonen, transformeren en modelleren van data)
* **Datacommando's & Logica:** Basic DAX (Calculated Columns, Measures)
* **Datavisualisatie:** Power BI, Excel (Draaitabellen, Grafieken, Dynamische Dashboards)

---

##  Uitgelichte Projecten

### 1. Slurpini Vivino Export Dashboard (Power BI)
* **Bestand:** `Slurpini Vivino Export Dashboard Fin...`
* **Omschrijving:** In dit project heb ik een export van Vivino-wijngegevens geanalyseerd. Met Power Query heb ik de ruwe data opgeschoond en gestructureerd, waarna ik in Power BI een visueel dashboard heb gebouwd om trends in wijnbeoordelingen, prijzen en regio's inzichtelijk te maken.

### 2. Case DataPower BI (Power BI & DAX)
* **Bestand:** `Case DataPower BI Hanane Final.pbix`
* **Omschrijving:** Een uitgebreide business case waarin data uit verschillende bronnen is gecombineerd. Hierin heb ik met basic DAX-formules klantspecifieke statistieken en KPI's berekend om bedrijfsprestaties live te monitoren.

### 3. Dashboard Brand Performance Analyse (Excel)
* **Bestand:** `Dashboard Brand Performance Analy...`
* **Omschrijving:** Een geavanceerd Excel-project waarin merkprestaties centraal staan. Door gebruik te maken van geavanceerde formules (zoals X.ZOEKEN/XLOOKUP) en interactieve draaitabellen, is er een overzichtelijk dashboard gecreëerd voor directie-rapportages.
